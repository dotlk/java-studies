* Registrar minha evolução no aprendizado de Java.
* Revisar conceitos fundamentais da linguagem.
* Armazenar exemplos práticos e exercícios.
* Servir como material de consulta para estudos futuros.

## Projeto Final

### Sistema de Ranking de Jogadores

Projeto desenvolvido utilizando:

* `HashMap`
* `ArrayList`
* `Collections`
* `JOptionPane`
* Estruturas condicionais e de repetição

O sistema permite:

* Adicionar jogadores e pontuações.
* Armazenar os dados dinamicamente.
* Exibir um ranking ordenado pela maior pontuação.
